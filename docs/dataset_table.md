# Dataset Table (Reviewer 3, Comment 1)

This file is a placeholder. Run:

    python -m src.generate_dataset_table

after pointing `config.yaml::data.root_dir` at your local ADNI export.
The script overwrites this file with real subject/image counts computed
from disk, plus `TODO` cells for age/sex/imaging-protocol that must be
filled in from your ADNI clinical metadata (not derivable from image
pixels alone).
